# NLP Portfolio

Коллекция ноутбуков с практическими проектами и экспериментами по обработке естественного языка (NLP). Основные темы: классификация русскоязычных текстов, тематическое моделирование, кластеризация сообщений и дообучение языковых моделей.

## Основные проекты

| Проект | Содержание |
|---|---|
| [Классификация обращений](projects/petition-classification/) | TF-IDF + CatBoost и сравнение RNN, LSTM и GRU для категоризации русскоязычных обращений. |
| [Классификация сообщений](projects/message-classification/) | Сравнение признаков RuBERT с CatBoost и fine-tuning RuBERT для классификации сообщений. |
| [Тематическое моделирование отзывов](projects/review-topic-modeling/) | Эмбеддинги, TF-IDF, UMAP, DBSCAN и извлечение ключевых слов для кластеров отзывов. |
| [Кластеризация сообщений](projects/message-clustering/) | Sentence embeddings, DBSCAN/HDBSCAN и интерактивное исследование кластеров. |
| [Fine-tuning Gemma 3](projects/gemma-sft/) | Эксперименты с supervised fine-tuning Gemma 3 270M и проверкой генерации. |

## Учебные материалы и черновики

В [`archive/`](archive/) сохранены учебные ноутбуки, варианты экспериментов, дубли и незавершённые заготовки. Они доступны для изучения, но не включены в список основных проектов портфолио.

## Технологии

Python, Jupyter, pandas, scikit-learn, PyTorch, Hugging Face Transformers, Sentence Transformers, CatBoost, UMAP, DBSCAN/HDBSCAN.

## Данные и воспроизводимость

Ноутбуки отражают исследовательские эксперименты и не образуют полностью автономный пакет. Часть из них ссылается на локальные наборы данных, веса моделей и артефакты в `../../data` или на локальные GPU/API; эти файлы в репозитории не хранятся. Для запуска потребуется подготовить исходные данные и установить зависимости, указанные в импортируемых библиотеках. Перед публикацией результатов следует повторно запустить ноутбук на доступных данных и зафиксировать версии библиотек и метрики.

Некоторые наборы данных содержат личную переписку или обращения. В репозитории оставлены только ноутбуки; исходные данные и приватные сообщения не добавлялись.
